Worker Node란

  • Kubernetes Pod가 실제로 실행되는 VM입니다.
  • API Node와 달리 외부 요청을 직접 받지 않습니다.
  • 큐의 작업을 꺼내 오래 걸리는 계산·문서 처리를 수행합니다.
  • SG-Worker는 인바운드 없이 MQ, DB, AI, Object Storage 쪽으로만 연결합니다.

리움 Worker 기능

  • 시험성적서·성분표 OCR: PaddleOCR 자체호스팅 기본
  • 공공데이터 수집·정제, ETL, 배치 재처리
  • 정책·법령 문서 RAG ingestion, pgvector/DB 적재
  • 대시보드·정책 리포트·통계·GIS·매칭 보조 작업

몇 개를 쓰나

  • Production Worker Node Pool: 4vCPU/8GB급 ×2 상시
  • AZ-A 1대 + AZ-B 1대로 최소 이중화합니다.
  • Worker Pod는 KEDA로 ×N 증감합니다.
  • Node는 작업량 증가 시 2→6대 확장 후보입니다.
