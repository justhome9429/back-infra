c4-g3는 어디에 쓰나

  • API Node와 Worker Node의 4vCPU/8GB급 기준 후보입니다.
  • 사용자 요청은 API Pod가 처리하고, 오래 걸리는 작업은 Worker Pod가 처리합니다.
  • 처음부터 큰 서버 1대를 두기보다 여러 Node와 Pod로 수평 확장합니다.

T4 GPU Server는 어디에 쓰나

  • NAVER 기준 자체호스팅 LLM의 T4 GPU 후보입니다.
  • Qwen3-8B-AWQ처럼 양자화한 8B급 모델을 비용 현실적인 선에서 PoC하기 위한 기준선입니다.
  • 두 대는 하나의 큰 GPU가 아니라 독립 LLM Replica 2개입니다.

주의할 점

  • 서버 타입명은 견적·리전·재고에 따라 최종 확인이 필요합니다.
  • c4-g3와 T4 GPU Server는 역할이 다릅니다. CPU 작업과 LLM GPU 작업을 섞어 보지 않습니다.
  • 성능은 PoC에서 p95 latency, Queue 처리시간, tokens/s로 확정합니다.
