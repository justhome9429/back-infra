m2.c4m8와 NHN Cloud 인스턴스 타입

인스턴스 타입은 가상 서버의 vCPU, 메모리 조합입니다. 리움 구조도에서 쓰인 m2.c4m8은 Standard 계열의 4 vCPU / 8GB 서버 타입입니다.

m2.c4m8

Standard 계열 · 4 vCPU · 8GB Memory
리움 API/Worker Node 기본 단위

중간급 CPU 노드 vCPU:RAM = 1:2 공공 기준 196원/h

이름 읽는 법

m2는 Standard 계열입니다. c4는 vCPU 4개, m8은 메모리 8GB를 뜻합니다.

즉 m2.c8m16은 Standard 8 vCPU / 16GB, r2.c4m16은 Memory Optimized 4 vCPU / 16GB입니다.

어느 정도 성능인가

단일 서버 기준으로는 작은 장비보다 여유 있고, 대형 DB나 AI 추론용으로는 부족한 중간급입니다.

API 서버, 경량 Worker, OCR/ETL Pod를 여러 노드로 분산하기에 적당합니다.

리움에서의 의미

m2.c4m8 한 대가 전체 서비스를 혼자 감당하는 구조가 아니라, NKS Worker Node 여러 대가 Pod를 나눠 받습니다.

Prod 5대 + Val 2대 기준으로 비용 산정되어 있습니다.

주의할 점

vCPU/Memory만으로 실제 처리량이 확정되지는 않습니다. Python API, OCR, DB 대기, 외부 API 지연에 따라 달라집니다.

최종 검증은 p95 latency, CPU, memory, queue depth 부하테스트로 봐야 합니다.

가격은 리전/공공·일반 상품/서비스 조합에 따라 달라질 수 있습니다. 이 화면은 인프라 구조 이해를 위한 사양 중심 표입니다.

정리: m2.c4m8은 리움에서 “한 대로 모든 처리를 끝내는 서버”가 아니라, NKS가 여러 Worker Node 위에 Pod를 나눠 올릴 때 쓰는 균형형 기본 단위입니다. 리움처럼 API, OCR/ETL Worker, RAG 작업이 섞인 업무형 서비스에서는 처음부터 r2/x1 같은 고메모리 장비로 올리기보다 m2.c4m8 여러 대와 HPA/KEDA로 수평 확장하는 쪽이 설명과 운영이 쉽습니다.
